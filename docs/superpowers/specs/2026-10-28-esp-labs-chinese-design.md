# ESP32 Labs 简体中文单语言版：设计规格

## 目标

将 `agharsallah/esp-labs-web` 完整复刻为一个仅提供简体中文的 ESP32-S3 互动实验网站。首版在视觉、页面信息架构与交互行为上以原站为基线，不提供其他语言切换。

## 范围

保留原项目的全部用户可见模块及功能：

- 首页、全局导航、深浅主题、移动端布局和降低动态效果支持。
- 实验地图、全部课程、课程步骤、接线说明、模拟器、串口终端、勾选进度和本地恢复。
- ESP32-S3 开发板的引脚图与 3D 板卡浏览。
- 固件代码阅读器、导览和代码解释界面。
- 工作台状态与日志。
- 数据手册概览、外设页面、参考阅读器和阅读进度。
- 零件库及其插图。

不包含账号、服务端、在线协作或多语言切换。学习进度和偏好仍只保存在浏览器本地。

## 实现策略

以原开源项目的 React 19、Vite、React Router 和现有设计 token 为基线，以确保 UI、路由、模拟器、三维视图和本地状态行为与参考站一致。代码库将只保留简体中文翻译资源，并把语言初始化固定为 `zh-CN`；所有语言选择控件、语言参数分支和非中文语言资源将删除或不打包。

静态资料、实验数据和参考内容沿用原项目的数据布局。构建应在不依赖远程运行时服务的条件下完成；缺少可选的固件或参考资料时，对应模块应呈现原项目的既有降级状态，而不影响其余界面。

## 页面与数据流

Hash 路由保持不变，以便部署在任意静态目录。入口默认显示中文首页；课程、数据手册、零件库、设置等页面由既有路由提供。课程进度、最近访问内容、主题和无障碍偏好使用浏览器存储。实验台 JSON 和静态参考资料经构建产物或 public 目录读取。

## 交互与异常处理

- 懒加载的模拟器、三维模块和代码资料应保留加载、错误与空状态。
- 实验步骤和模拟终端可交互；状态更新后应立即反映在课程与总进度中。
- 窄屏布局保留导航和课程可读性。
- 尊重 `prefers-reduced-motion`，键盘焦点始终可见。
- 任何可选资料加载失败都必须局部降级，并给出中文说明，不能阻断主应用。

## 验收标准

1. 所有原站核心路由在简体中文下可访问，且不显示语言切换入口或其他语言文案。
2. 实验课程、模拟器、引脚/3D、代码阅读器、工作台、数据手册和零件库均可进入并执行其原有前端交互。
3. 主题、进度与最近访问状态刷新后仍能恢复。
4. 桌面和约 390px 宽移动视口没有横向溢出，主要操作可用。
5. 类型检查、代码检查、自动化测试和生产构建均通过。

## 验证计划

以原项目的 `check` 与 `build` 命令作为基础验证；补充单语言配置、关键路由和本地进度行为的自动化测试。完成后对桌面及移动视口进行视觉巡检，并逐项对照本规格的验收标准。
